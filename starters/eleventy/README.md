# TagBrush.css Eleventy starter

A minimal [Eleventy](https://www.11ty.dev) site: a home page with the latest posts as cards, a posts list, and post pages at a comfortable reading width. The templates are plain HTML with no classes.

```sh
npx degit kovirlabs/tagbrush/starters/eleventy my-site
cd my-site
npm install
npm start
```

- Code blocks are highlighted by the official syntax-highlight plugin (Prism classes), and TagBrush.css colors them in light and dark mode.
- Change the look with CSS variables in a `<style>` block in `_includes/base.njk`, or build one with the [theme builder](https://kovirlabs.github.io/tagbrush/#theming).
