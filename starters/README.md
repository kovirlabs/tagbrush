# Starters

Ready-made starting points that use TagBrush.css with no classes in the templates. Each one has a home page with the latest posts as cards, a posts list, and post pages at a comfortable reading width, with highlighted code that follows dark mode.

| Starter | Get it |
|---|---|
| [Pandoc](pandoc/) | One command turns a Markdown file into a styled page |
| [Hugo](hugo/) | `npx degit kovirlabs/tagbrush/starters/hugo my-site` |
| [Eleventy](eleventy/) | `npx degit kovirlabs/tagbrush/starters/eleventy my-site` |
| [Astro](astro/) | `npx degit kovirlabs/tagbrush/starters/astro my-site` |

For a single page with no tools at all, copy [`starter.html`](../starter.html).

Every starter is built by CI on each change (`.github/workflows/starters.yml`).
