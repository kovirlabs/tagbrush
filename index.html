<tagbrush>

A tiny, no-build CSS library that makes plain semantic HTML look clean and modern. One file. No classes required. Themeable with CSS variables, with dark mode built in.

Why TagBrush.css?

No build step

Plain CSS. No PostCSS, no bundler, no config. Drop in a <link> and you're done.

Classless by default

Headings, forms, tables, buttons and code blocks are styled out of the box. Write HTML, not class soup.

Themeable with variables

Colors, fonts, spacing and radius are semantic CSS custom properties. Override a few to make it yours.

Easy to override

Everything lives in a @layer, so your own CSS always wins. No !important, no specificity battles.

Dark mode built in

Follows the visitor's system setting automatically, or force it with data-theme="dark" on any element.

Tiny

About 4 KB gzipped, with zero dependencies and zero JavaScript.

Astro friendly

Import it once in your layout and every page picks it up. Works with any static site generator.

Open source

Apache 2.0 licensed. Fork it, tweak it, ship it.

Build your theme

Every component on this page reads from a handful of CSS variables. Change them here and the whole page updates live, then copy the CSS into your site. Hover colors and focus rings are derived from --color-primary automatically.

Dark mode

TagBrush.css follows the visitor's system preference. Use the switcher at the top of the page, or set data-theme on any element to force a scheme for just that part of the page:

data-theme="light"

Always light, whatever the system setting.

data-theme="dark"

Always dark, whatever the system setting.

Get started

1. Add the stylesheet

Use the CDN, or download tagbrush.css and host it yourself.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/kovirlabs/tagbrush@main/tagbrush.css">

2. Write semantic HTML

<main class="container">
  <h1>Hello, world</h1>
  <p>It already looks good.</p>
  <button>Click me</button>
</main>

3. Make it yours (optional)

<style>
  :root {
    --color-primary: #10b981;
    --font-family-base: "Inter", sans-serif;
    --border-radius: 0.5rem;
  }
</style>

Because TagBrush.css lives in its own cascade layer, any rule you write wins, even a plain button { … } selector. No !important needed.
